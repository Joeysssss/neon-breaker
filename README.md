# NEON BREAKER｜霓虹打磚塊

一款使用 HTML5 Canvas 製作的霓虹風格打磚塊網頁遊戲。玩家需要控制能量擋板接住球體、擊碎所有磚塊，收集隨機掉落的強化道具，並挑戰難度逐漸提升的關卡。

## 線上遊玩

不需下載或安裝，直接開啟：

**[立即遊玩 NEON BREAKER](https://joeysssss.github.io/neon-breaker/)**

## 遊戲特色

- 純 HTML、CSS、JavaScript 製作，不需要安裝額外套件
- 支援鍵盤、滑鼠及觸控操作
- 五種循環變化的磚塊排列
- 關卡越高，磚塊的耐久度與球速也會逐漸提升
- 具有三條生命、暫停、重新開始及音效控制功能
- 自動將最高分保存在瀏覽器的 `localStorage`
- 響應式介面，可在桌面與行動裝置遊玩

## 開始遊戲

### 直接開啟

使用瀏覽器開啟 [`index.html`](./index.html) 即可開始遊玩。

### 使用本機伺服器

也可以透過任意靜態檔案伺服器執行，例如 VS Code 的 Live Server 擴充功能。

啟動伺服器後，在瀏覽器開啟伺服器提供的網址即可。

## 操作方式

| 操作 | 功能 |
| --- | --- |
| `←` / `→` | 向左或向右移動擋板 |
| `A` / `D` | 向左或向右移動擋板 |
| 滑鼠移動 | 控制擋板位置 |
| 觸控拖曳 | 在行動裝置上控制擋板 |
| `Space` | 發射球體或暫停／繼續遊戲 |
| 點擊遊戲區 | 球體尚未發射時進行發射 |

## 道具說明

部分發光磚塊被擊碎後會隨機掉落道具。必須使用擋板接住道具才能生效。

| 道具 | 效果 |
| --- | --- |
| 分裂核心 `+1` | 額外增加一顆球 |
| 磁場擴張 `↔` | 暫時加寬擋板 |
| 超頻脈衝 `»` | 提高目前所有球體的速度 |
| 時間緩速 `⌁` | 降低目前所有球體的速度 |

## 關卡與分數

- 清除畫面中的所有磚塊即可通過一關。
- 每通過一關，分數增加 `1`。
- 隨著關卡提升，會出現需要撞擊多次才能破壞的磚塊。
- 磚塊上的數字代表目前剩餘耐久度。
- 每個新關卡會依照關卡編號切換不同排列方式。
- 球全部掉出畫面時失去一條生命；生命歸零後遊戲結束。
- 最高通關分數會自動儲存在目前使用的瀏覽器中。

## 使用技術

## 瀏覽器支援

建議使用最新版 Chrome、Edge、Firefox 或 Safari。瀏覽器必須支援 Canvas、Web Audio API 與 `localStorage`。

## 重設最高分

若要清除最高分，可在瀏覽器開發者工具的 Console 執行：

```javascript
localStorage.removeItem('neonBreakerBest');
location.reload();
```
